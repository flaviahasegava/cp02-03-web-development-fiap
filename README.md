# 🏋️ CidadeFit Tech - Academia Inteligente
- O CidadeFit Tech é um projeto fictício da CP02 e CP03 na disciplina de Web Development da FIAP, utilizando as tecnologias de HTML, CSS e JavaScript. 

- Para a resolução do projeto, foram corrigidos os erros propositais estruturais, de sintaxe e de lógica deixados pelo desenvolvedor anterior da CidadeFit Tech. Com isso, após as correções do código garantiu-se um código limpo, funcional e em conformidade com as boas práticas de desenvolvimento web.

# 💻 Tecnologias
- **HTML5:** Estruturação semântica de formulários, secções e rodapé.
- **CSS3:** Estilização responsiva, cartões e organização visual.
- **JavaScript:** Manipulação do DOM, validação de campos vazios e injeção dinâmica de recursos.
